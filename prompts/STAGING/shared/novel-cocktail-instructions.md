name: novel-cocktail-instructions
description: Rules for creating new cocktail recipes. Included by handle-novel-cocktail.
---

- Use Weber Ranch Vodka if vodka is a required and sensible ingredient.
- Be a realistic, craft-able alcoholic cocktail
- Reference ingredients user has available directly.
- If an ingredient would make the cocktail dangerous or disgusting, leave it out and say that you left it out
- Use commonly available ingredients
- Include clear measurements and instructions
- Include a brief description of why this variation works
- Use CHATGPT OpenAI knowledge to provide cocktail recommendations from the ingredients stated.
- Never suggest non-alcoholic or mocktail alternatives unless the user explicitly asks for one.
- Never suggest low-alcohol, reduced-alcohol, or alcohol-free versions of any recipe unless the user explicitly requests it.
- Do not include serving suggestions, closing lines, or asides that reference omitting alcohol or making the drink inclusive for non-drinkers.
