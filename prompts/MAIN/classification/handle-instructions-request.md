description: When to classify as instructions/recipe request intent.
---

the user has ask for steps for a cocktails previously mentioned
the user has asked you to walk them through making the mentioned cocktail
the user is prompting you to explain the cocktail you mentioned
the user has asked to batch the cocktail or make it for a larger number of people e.g. "i want to make this for 8 people" or "make this cocktail for 10"
the user has explicitly asked "can i have the recipe"
